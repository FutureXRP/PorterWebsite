# Photos

Drop photos into this folder with the exact filenames below and the site picks
them up automatically. Until a file exists, each spot shows a solid blue panel
with the company's credentials, so nothing looks broken while you gather
pictures.

| File | Where it shows | Best shape | What to use |
|------|----------------|------------|-------------|
| `hero.jpg` | Behind the home page hero (under a dark blue overlay) and in the "Why Porter & Co." section | Landscape, 1800 px wide | Matt on the job, a clean install, or the truck. Detail matters less in the hero because of the overlay. |
| `water-heater.jpg` | "Tank or Tankless" section | 4:5 portrait, 1200 px wide | A finished water heater install with clean pipework |
| `matt.jpg` | About page | 4:5 portrait, 1200 px wide | A real portrait of Matt, ideally in work clothes at a job site. Do not use stock here. |

Real job photos from the truck beat stock every time. If you need stock to
start, these sources allow commercial use with no attribution required:

- Unsplash: https://unsplash.com/s/photos/plumber and https://unsplash.com/s/photos/water-heater
- Pexels: https://www.pexels.com/search/plumber/
- Pixabay: https://pixabay.com/images/search/plumbing/

Keep each file under about 400 KB (export at JPEG quality 75 to 80) so the
page stays fast on phones.
