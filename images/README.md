# Photos

Drop photos into this folder with the exact filenames below and the site picks
them up automatically. Until a file exists, the page shows a built-in
illustration in that spot, so nothing breaks while you gather pictures.

| File | Where it shows | Best shape | What to use |
|------|----------------|------------|-------------|
| `hero.jpg` | Home page hero | 4:3 landscape, 1600 px wide | Matt on the job, or a clean tankless install |
| `water-heater.jpg` | "Tank or tankless" section | 4:5 portrait, 1200 px wide | Finished water heater install |
| `matt.jpg` | About page | 4:5 portrait, 1200 px wide | Portrait of Matt (this should be a real photo, not stock) |
| `band.jpg` | Dark call-to-action bands | Wide landscape, 2000 px wide | Tools, pipes, or a van; it sits under a dark overlay so detail does not matter |
| `work-1.jpg` … `work-6.jpg` | "Recent work" gallery | 4:3 landscape, 1200 px wide | Real job photos in this order: tankless conversion, tank replacement, gas line, kitchen faucet, shower valve, main shut-off valve |

Real job photos from the truck will always beat stock. If you need stock to
start, these free sources allow commercial use with no attribution required:

- Unsplash: https://unsplash.com/s/photos/plumber and https://unsplash.com/s/photos/water-heater
- Pexels: https://www.pexels.com/search/plumber/
- Pixabay: https://pixabay.com/images/search/plumbing/

Keep each file under about 400 KB (export at JPEG quality 75 to 80) so the
page stays fast on phones.
